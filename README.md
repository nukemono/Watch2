# Watch2 — SolarWatch 高精度再現版

このリポジトリは、卒業制作 SolarWatch で**以前に精度が高かったと考えられる測定コードを再現し、実機で検証するための単一プロトタイプ**です。

## 基準

- 元リポジトリ: `nukemono/Watch`
- 元PR: `#36 DO NOT MERGE: Watch2 high-accuracy control snapshot`
- 測定ロジック基準コミット: `fa45d6915e354bd6cb09b38640278ae6cc122c0f`
- 高精度候補コードの保存コミット: `80ca9d9581fe6917d17a99316803db82cd429beb`
- 現在の測定ページ: `iphone-field.html`

## 方針

Watch2ではプロトタイプを複数に分岐させない。

`iphone-field.html` だけを測定対象とし、高精度候補の基準コードを土台に、実機検証で必要と判断された変更だけを最小限に統合する。

Git履歴をロールバック手段とし、`beta版`、`flex版`などの派生HTMLは作らない。

## 現在の明示的な変更

1. **カメラ高度角は2D方式**
   - `DeviceOrientation beta` を使用する。
   - 0〜360°へ正規化する。
   - 水平を0°とし、液晶面を手前へ持ち上げる方向に180°へ近づき、そのまま一周を360°として扱う。
   - 3D光軸高度は主値には使わない。

2. **手持ち測定を許可**
   - 姿勢安定性、方位SD、回転速度は診断値として記録する。
   - これらを測定開始の必須条件にしない。
   - 通常の手ブレで10秒測定を途中終了しない。
   - 最終結果も安定性だけでは無効化しない。

3. **維持する基準ロジック**
   - iPhone方位は `webkitCompassHeading` と180°ジャンプ/parity補正を使用する。
   - GPS処理、太陽位置計算、時刻推定ロジックは高精度候補の基準コードを維持する。
   - 10秒 / 50msサンプリングを維持する。
   - CSV保存を維持する。

今後の修正対象は常に `iphone-field.html` のみとする。
